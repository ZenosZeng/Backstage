# Backstage 工作区

实质性任务开始时加载 `backstage-memory` Skill，按本机配置选择本地读取或 S3 同步。
工具位于工作区的 `.agents/`；项目路径由其中的 `config.json` 注册。

记忆用于导航，重要结论以当前 Git、源码、配置、测试和真实环境为准。
只记录可复用的事实、决策、验证与风险，保留来源；不保存 secret、完整聊天和原始日志。
记忆命令的 `--agent` 填写实际执行者，不把其他 Agent 的工作归到自己名下。
跨仓任务使用稳定 task ID，暂停、恢复、完成按用户决定追加状态，待办候选不构成执行授权。

项目专属的工程约定写在各仓库的 `AGENTS.md`，长期导航维护在 `.share/knowledge/`。
