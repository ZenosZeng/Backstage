# Backstage 只读工作台

在已有工作区中启动：

```bash
pixi install --locked
pixi run web
```

打开 `http://127.0.0.1:8787`。服务在前台运行，按 Ctrl+C 停止；自定义端口用
`pixi run web --port 8788`。首次使用需先完成 [本地工作区初始化](../../examples/README.md)。

远程工作区通过 SSH 或 Coder 将端口转发到访问者电脑；例如在电脑上运行：

```bash
ssh -N -L 8787:127.0.0.1:8787 <workspace-host>
# 或使用已登录的 Coder CLI
coder port-forward <workspace> --tcp 8787:8787
```

随后在电脑打开同一个本机地址。MVP 仅监听 127.0.0.1，并检查 Host；不提供公开访问、
登录系统或任意域名代理。私有记忆、项目文档及配置不打包进静态资源，也不发布到托管网站。

## 页面

- 总览：优先展示最近进展和仍需核对的风险/假设，再展示业务项目；事件数量和活动图降为辅助。
- 项目：以 `.share/knowledge/projects/*.md` 为业务入口，读取同名 JSON 中已整理的事件
  关联，聚合跨仓记忆。支持现有直接事件和 `source/event` 包装格式。新记录延续明确唯一的
  task 关联，或按与知识页 slug 一致的 task/topic 命名空间关联；不以重叠仓库标签扩散归属。
  关联是导航，不能代替事实核验。保留原始事件、仓库标签及来源；未归属记录仍可从全局记忆查找。
  没有项目知识的工作区暂展示仓库入口，并明确标识。
- 记忆与时间线：分别按业务项目、来源仓库，以及内容、Agent、机器和类型筛选，分页浏览；默认排除被明确取代
  的记录，可切换历史；抽屉展示来源、验证依据、原始事件和前后修正。
- 文档：先选择业务项目，阅读项目知识、同名架构图、知识页引用的报告及对应 docs 子目录；
  也可进入“全部文档”。浏览 `.share/knowledge`、`.share/docs`、公共 `docs/tools/examples` 中的文档和根 README；支持标题/
  路径筛选、Markdown 表格、相对文档链接、图片与 SVG 预览。Markdown 不执行原始 HTML，
  SVG 在受限 iframe 中展示。目录以外文件及逃逸符号链接不开放。
- 运行：本机服务进程与就绪状态；训练/评测调用现有 `--once --no-notify` 检查。
  监控配置沿用 `.local/config/watchdog-{train,b1k}.json`。不发送通知，不保存监控游标，
  不启停 Agent、训练、评测或服务。明确展示本机范围、来源配置/采集入口及采样时间；
  区分未配置、不可用、无数据和已有结果。监控返回空内容不能证明没有活跃任务。

页面由纯 HTML/CSS/JavaScript 组成，不需要 Node/npm 或前端构建。Python 标准库提供
本机 HTTP 服务，`markdown-it-py` 负责文档渲染；通过原有 Pixi 环境安装。

右上角太阳/月亮按钮可切换深浅色模式。首次打开跟随系统偏好，手动选择保存在当前
浏览器的 localStorage，刷新及再次打开时保留；记忆、任务和运行模块在两种模式下
保持紫、暖橙和蓝青的区分。

## 数据与时间

点击右上角刷新，首版不自动采集或轮询。总览、记忆和文档目录共享同一个进程内快照，
TTL 为 3 秒；过期后的并发请求只重建一次，事件、任务状态、业务关联与目录一同更新，
不维护额外查询缓存或持久索引。页面标明采样时间，刷新最多仍可能复用 3 秒内的快照。
正文采用 13–14px，主要辅助信息采用 11–12px；深浅两种主题和手机布局均需浏览器验证。

记忆来源机器只显示最后事件时间，
不能据此判断在线状态；`shared 基线`是本机同步基线目录更新时间，不是 raw 同步成功时间。
任务的 `unknown/conflict` 如实展示，不从旧待办推断任务仍在进行。

监控信息仅来自本机配置可读的环境；跨机实时采集和历史训练曲线不在此版本范围。
当前页读取时间不等于指标产生时间。数据校验失败会提示部分数据不完整。

可指定其他已有工作区：

```bash
pixi run web --root /path/to/.agents --local-root /path/to/.agents/.local
```

`--root` 控制记忆和文档来源，`--local-root` 控制本机配置/服务记录来源。读取业务监控
仍使用当前工具核心的 `--once` 实现。工作台没有修改记忆、编辑文档或网页遥控接口。
